# LeetCode Solutions

My solutions to LeetCode problems, automatically organized using [Code Bridge](https://github.com/pranavkaushikdhara/GitCode).

## Structure

Each problem has its own folder containing:
- `problem.txt` - Problem statement
- `solution.[ext]` - Solution code

```
two-sum/
├── problem.txt
└── solution.java

valid-parentheses/
├── problem.txt  
└── solution.js
```
